# Photopic Frontend

Modern privacy-first face recognition photo filtering application frontend.

## Tech Stack
- **Framework**: React 19
- **Build Tool**: Vite 6
- **Styling**: TailwindCSS 4
- **Icons**: Lucide React
- **Animations**: Motion

## Scripts
- `npm run dev`: Start Vite development server
- `npm run build`: Build production client bundle
- `npm run preview`: Preview production build
